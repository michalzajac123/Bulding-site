# 👷 Building site 

A single-page web application built with **Vue 3**, **TypeScript**, **Vite**, and **Tailwind CSS**.  
This repository includes a ready-to-use setup for local development, production builds, and simple static deployment.

---

## 📦 Installation

Clone the repository and navigate to the main directory:

```bash
git clone https://github.com/YourRepo/Building-stie.git
cd Building-site
```



## 🧑‍💻 Development Setup

### Backend

```bash
npm install
npm run start
```
